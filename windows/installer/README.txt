Сборка локального установщика Windows

Упаковка использует готовые build/OpenAoK.exe и SDL2.dll, подготовленные
assets, шрифты, музыку и пакет mods/worldcraft. Движок повторно не компилируется.
Получатель устанавливает игру без Python, компилятора и подготовки данных.

Компилятор: переносимый NSIS 3.13.
  https://sourceforge.net/projects/nsis/files/NSIS%203/3.13/nsis-3.13.zip/download
  SHA-256: ba63dffc4410ee89193e1cb5a41989991bd77c61068da17e3156d136b7b0b3d8
Справочник сценария:
  https://nsis.sourceforge.io/Docs/Chapter4.html

Из корня рабочего каталога:
  python OpenAoK-source/windows/installer/Build-Installer.py --nsis OpenAoK-build-support/installer-tools/nsis-3.13/makensis.exe

Результат: installers/OpenAoK-Worldcraft-<версия>-win64-Setup.exe,
контрольная сумма и installer-manifest.json. Рабочие файлы и полный список
хешей находятся в OpenAoK-build-support/installer/work-<дата-время>.
Повторная упаковка создаёт отдельный рабочий каталог без удаления старого.

Проверка готового установщика:
  python OpenAoK-source/windows/installer/Verify-Installer.py
Она требует отсутствия уже установленной копии, создаёт отдельную тестовую
папку, сверяет все файлы, запускает 10 проверок движка, меню и матч с посадкой,
затем проверяет удаление с сохранением постороннего файла. Средства разработки
исключаются из PATH запускаемой игры. Отчёт verification.json, снимки и журналы
сохраняются в рабочей папке упаковки. Это проверка на текущем компьютере;
она не заменяет испытание на отдельной чистой Windows.

Для NSIS параметры /D= и _?= должны быть последними и без кавычек даже
при пробелах в пути. Проверяющий сценарий учитывает это правило.
  https://nsis.sourceforge.io/Docs/Chapter3.html

Установка: для текущего пользователя, по умолчанию в
%LOCALAPPDATA%/Programs/OpenAoK Worldcraft. Ярлыки указывают рабочую папку build.
Удаление использует точный список установленных файлов и сохраняет профиль,
сохранения и посторонние файлы. Рекурсивное удаление папки установки не применяется.

Установщик содержит локальные игровые данные и шрифты. Он не предназначен
для публичной загрузки в GitHub; в репозитории хранятся только эти сценарии.
